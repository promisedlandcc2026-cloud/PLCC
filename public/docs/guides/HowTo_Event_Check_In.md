# How-To Guide: Using the Event Check-In System
**Promised Land Christian Center (PLCC)**  
**For:** Volunteers, Staff, Ministry Leaders  
**Last Updated:** April 21, 2026

---

## What You'll Learn
This guide shows you how to use PLCC Connect's Event Check-In system to quickly check in members and track attendance at services and events.

---

## Quick Start (3 Steps)

1. **Search** for the person by name or access code
2. **Select** the person from results
3. **Confirm** check-in

That's it! The system handles the rest.

---

## Detailed Instructions

### Opening the Check-In Page

**Step 1:** Log in to PLCC Connect
- Go to https://plcc-vault.vercel.app
- Enter your email and password
- Click "Sign In"

**Step 2:** Navigate to Events
- Click "Events" in the main navigation
- Select "Check-In" from the dropdown

**Step 3:** Choose Check-In Mode
- **Kiosk Mode**: For staff-operated check-in stations
- **Mobile Express**: For self-service family check-in

---

### Checking In a Member

**Method 1: Search by Name**
1. Type the person's first or last name in the search box
2. Results appear as you type
3. Click on the correct person
4. Click "Check In" button
5. Confirmation appears with timestamp

**Method 2: Search by Access Code**
1. Ask the person for their 4-digit access code
2. Type the code in the search box
3. Their profile appears automatically
4. Click "Check In" button
5. Done!

**Method 3: QR Code Scan** (if enabled)
1. Click the QR scanner icon
2. Allow camera access
3. Have person show their QR code
4. System scans and checks them in automatically

---

### Checking In Multiple Family Members

**Step 1:** Search for any family member
- Type family name or any member's name
- Example: "Smith" shows the whole Smith family

**Step 2:** Select multiple people
- Check the box next to each person checking in
- You can select parents and children together

**Step 3:** Bulk check-in
- Click "Check In Selected" button
- All selected members are checked in at once
- Confirmation shows all names

---

### Viewing Today's Attendance

**Step 1:** Click "Attendees" tab
- See everyone checked in today
- View check-in times
- See total count

**Step 2:** Filter by service or event
- Select service type from dropdown
- View specific event attendance
- Export list if needed

**Step 3:** Search checked-in members
- Use search box to find specific person
- Verify they're checked in
- See their check-in time

---

### Handling Special Situations

**Visitor (Not in System)**
1. Click "Register Visitor" button
2. Enter their information:
   - First and last name
   - Phone number
   - Email (optional)
3. Click "Save and Check In"
4. They're added to system and checked in

**Late Arrival**
- Just check them in normally
- System records actual check-in time
- No special steps needed

**Early Departure**
- No check-out required
- System tracks check-in only
- Note in comments if needed

**Duplicate Check-In Attempt**
- System prevents double check-ins
- Shows "Already checked in at [time]"
- No action needed

## Tips for Success

### Speed Tips
- **Use Access Codes**: Fastest method for regular attendees
- **Type Partial Names**: "Smi" finds "Smith" quickly
- **Family Check-In**: Check in whole families at once
- **Keep Tablet Charged**: Always have backup power

### Accuracy Tips
- **Verify Identity**: Make sure you have the right person
- **Check Spelling**: Similar names can cause confusion
- **Update Info**: If member says info is wrong, note it
- **Report Issues**: Tell admin about system problems

### Customer Service Tips
- **Smile and Greet**: Make check-in welcoming
- **Be Patient**: Help first-time users
- **Explain Process**: Tell visitors what to expect
- **Thank Them**: Appreciate their attendance

## Troubleshooting

### "Person Not Found"
**Try:**
- Different spelling of name
- First name only or last name only
- Ask for their access code
- Register as visitor if truly new

### "System is Slow"
**Try:**
- Check internet connection
- Refresh the page
- Close other browser tabs
- Restart device if needed

### "Cannot Check In"
**Possible Causes:**
- Person already checked in (see message)
- System maintenance (rare)
- Permission issue (contact admin)
- Internet connection lost

### "Wrong Person Checked In"
**Solution:**
1. Note the person's name and time
2. Contact admin staff immediately
3. They can remove incorrect check-in
4. Check in correct person

## Mobile Device Setup

### For iPads/Tablets

**Step 1:** Add to Home Screen
1. Open Safari/Chrome
2. Go to check-in page
3. Tap Share button
4. Select "Add to Home Screen"
5. Name it "PLCC Check-In"

**Step 2:** Enable Kiosk Mode (Optional)
1. Go to Settings → Accessibility
2. Enable Guided Access
3. Set passcode
4. Triple-click home to lock app

**Step 3:** Position Device
- Place at entrance or welcome desk
- Ensure good lighting for QR scanner
- Keep charger connected
- Angle screen away from direct sunlight
