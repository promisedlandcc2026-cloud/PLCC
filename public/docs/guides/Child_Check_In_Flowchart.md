    🔒 Unique 4-digit code for each check-in
    🔒 Code must match (photo or written)
    🔒 Backup code available if needed
    🔒 Allergy alerts visible to volunteers
    🔒 All check-ins logged with timestamp


╔═══════════════════════════════════════════════════════════════╗
║                                                               ║
║                         TIME ESTIMATE                         ║
║                                                               ║
╚═══════════════════════════════════════════════════════════════╝


    First Time (with consents):  ~5 minutes
    ├─ Search & Select:          30 seconds
    ├─ Sign 4 Consent Forms:     3 minutes
    ├─ See Code & Take Photo:    30 seconds
    └─ Drop Off:                 1 minute

    Regular Check-In:            ~2 minutes
    ├─ Search & Select:          30 seconds
    ├─ See Code & Take Photo:    30 seconds
    └─ Drop Off:                 1 minute


╔═══════════════════════════════════════════════════════════════╗
║                                                               ║
║                      TROUBLESHOOTING                          ║
║                                                               ║
╚═══════════════════════════════════════════════════════════════╝


    ❓ Lost your code/photo?
    → Tell volunteer your child's name
    → Show your ID

    ❓ Don't have a phone for photos?
    → Write the number on your hand or paper
    → Or ask volunteer to print a label

    ❓ Consent forms won't submit?
    → Make sure you checked the agreement box
    → Make sure you signed (typed name or drew signature)

    ❓ Code not displaying?
    → Refresh the page
    → Or try checking in again
