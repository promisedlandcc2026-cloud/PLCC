# How-To Guide: Contribution Manager
**Promised Land Christian Center (PLCC)**  
**For:** Finance Team, Treasurers, Admin Staff  
**Last Updated:** July 23, 2026

---

## What You'll Learn
How to create a giving batch for a service date, enter gifts (name → amount → account), keep an entry log, and post batches from Contribution Manager—similar to the Servant Keeper Contribution Manager workflow.

---

## Overview

**Contribution Manager** is the batch hub. **Counting Session** is where you enter gifts.

1. **Create** a batch for that day’s date and save  
2. **Open** the batch (double-check the date you created)  
3. **Enter** gifts: Name → Amount → Account → Save Entry  
4. **Accounts** (funds) power the account list  
5. **Tag** and **Post** when the batch is complete  

**Who can use it:** Admin, Finance, Secretary, Asst. Secretary. Creating, archiving, and posting need finance edit permission.

---

## Quick Start (Sunday)

1. **Treasury → Contribution Manager** → **New Batch**  
2. Set **Batch Date** to today (or the service date), name it (e.g. `Todays Giving`), **Save & Open**  
3. In Counting Session: type a **Name**, enter **Amount**, pick **Account**, click **Save Entry** — repeat  
4. Click **Save Draft** as you go; when done, **Finalize & Lock** (or return to CM and **Post selected**)  
5. Back in Contribution Manager, confirm the batch shows as posted

## Part 1: Create a Batch for That Day’s Date

*(Like Servant Keeper → Batches → Add → Save)*

**Step 1:** On **Batches**, click **New Batch**.

**Step 2:** Enter:
- **Batch Date** — the service / giving date (save for *that* day)  
- **Batch Name** — e.g. `Todays Giving`  
- **Comments** — optional  

**Step 3:** Click **Save & Open**.

You land in **Counting Session** for that batch. The header shows **Batch Date · Batch # · Batch Name**.

---

## Part 2: Open an Existing Batch by Date

*(Like Unposted Batch Manager → select the date → Open)*

**Step 1:** On **Batches**, set **Show** to **Unposted** (or **All**).

**Step 2:** Find the row for the date you created (especially today’s batch).

**Step 3:** Select it, then click **Open**.

---

## Part 3: Enter Gifts (Counting Session)

This matches the Servant Keeper **Entry** flow.

### 3a. Name / Env #
- Click **Name / Env #** and start typing any letter of a name  
- Pick a member from the list when it appears  
- Or type a visitor name freely (e.g. `Visitors, Today`) if there is no match  

### 3b. Amount
- Click **Amount** and enter the dollar amount (e.g. `100`)  

### 3c. Account (Fund)
- Open **Account / Fund** — the list comes from **Accounts** / Fund Management  
- Choose where the gift goes (Tithes and Offerings, Building Fund, Missions, etc.)  
- Accounts are required; set them up under Contribution Manager → **Accounts** or **Fund Management**  

### 3d. Payment type & Save
- Choose **Cash**, **Check**, **Credit/Debit**, **Online**, or **Other**  
- For checks, fill **Check #**  
- Optional: **Note**, **Tax deductible**  
- Click **Save Entry**  

The gift appears in the **Entry Log** at the bottom. Clear the amount and enter the next gift (name can stay for the same donor).

### Extra buttons
| Button | Use |
|--------|-----|
| **Clear Entry** | Reset the form |
| **Loose Plate** | Saves the current amount as “Loose Plate” cash to the selected account |
| **Save Draft** | Keeps your entry log if you leave and come back |
| **Finalize & Lock** | Posts gifts to the ledger and locks the session |

### Cash calculator
Collapsed under Entry Log — use it to count bills/coins for reconciliation. It does not replace Gift Entry; use **Loose Plate** or a Cash entry to assign plate cash to an account.

---

## Part 4: Accounts (Needed for Entry)

*(Like Servant Keeper Account Manager)*

1. Contribution Manager → **Accounts** tab — see active funds  
2. Or **Fund Management** / bottom link **Fund Accounts** — add or edit funds  

Those same accounts appear in the Counting Session **Account / Fund** dropdown. Without accounts, you cannot save entries properly.

---

## Part 5: Tag and Post from Contribution Manager

After Finalize & Lock (or if you only Saved Draft and will post from CM):

1. Return to **Contribution Manager → Batches**  
2. **Tag** the finished batch(es)  
3. Click **Post selected** (or use the **Post** tab)  
4. Confirm **Yes, post the tagged batch(es)** → **Post and Finalize**  

Posted batches move to the **Posted** filter and are locked.

## Typical Flow (Mapped to Servant Keeper)

| Servant Keeper | PLCC Canaan |
|----------------|-----------|
| Batches → Add → Save for that date | Contribution Manager → **New Batch** → Save & Open |
| Unposted Batch Manager → Open by date | Batches → select date → **Open** |
| Entry → Name/Env | Gift Entry → **Name / Env #** |
| Entry → Amount | Gift Entry → **Amount** |
| Entry → Account Name | Gift Entry → **Account / Fund** |
| Save Entry | **Save Entry** → Entry Log |
| Accounts toolbar | **Accounts** tab / Fund Management |
| Post Batch | **Finalize & Lock** and/or CM **Post selected** |

## Troubleshooting

| Issue | What to try |
|-------|-------------|
| No accounts in the dropdown | Add funds under **Accounts** / Fund Management first |
| Name search empty | Type at least 2 letters; or enter a visitor name manually |
| Draft entries missing after reopen | Use **Save Draft** before leaving; entries are stored with the session |
| Can’t finalize | Enter at least one gift (or cash calculator total) and ensure you have edit permission |
| Post does nothing in CM | **Tag** the batch first |
