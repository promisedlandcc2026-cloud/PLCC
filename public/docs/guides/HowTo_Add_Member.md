# How-To Guide: Adding Members & Families
**Promised Land Christian Center (PLCC)**
**For:** Admin Staff, Secretaries, Ministry Leaders
**Last Updated:** July 27, 2026

---

## Overview

This guide covers three tasks:
1. Adding a new adult member to the Vault
2. Creating a household (family unit)
3. Adding a child to an existing household

**Who can do this:** Admin, Secretary, Asst. Secretary, and roles with People section access.

---

## Part 1 — Add a New Adult Member

### Where to go
**Top navigation → People section → Members**
Path: `/#/members`

### Steps

1. **Open Members**
   - Click **People** in the top navigation bar
   - The left sidebar shows People Tools
   - Click **Members**

2. **Click "Add Member"**
   - Look for the **Add Member** button in the top-right corner of the page

3. **Fill in the required fields**

   | Field | Notes |
   |-------|-------|
   | First Name | Required |
   | Last Name | Required |
   | Email Address | Used for login and communications |
   | Phone Number | Primary contact number |
   | Role | Set to Member, Volunteer, Staff, etc. (see Role Guide below) |
   | Status | Active (default) |

4. **Optional but recommended**
   - Date of Birth — enables birthday tracking and anniversary reminders
   - Address — required if mailing tax documents
   - Ministry Interests — helps with team assignments
   - Access Code — 4-digit code used for kids check-in kiosk lookup

5. **Save the member**
   - Click **Save** — the member record is created immediately
   - You can return to edit at any time

## Part 2 — Create a New Household (Family Unit)

A **Household** groups family members together. This is where you add children.

### Where to go
**People section → Households**
Path: `/#/households`

### Steps

1. Click **People** in the top navigation → **Households** in the left sidebar
2. Click **New Household** (top right)
3. Enter a **Household Name** (usually the family last name, e.g. "The Johnson Family")
4. Add **Address** if available
5. Click **Save Household**
6. The household is created — now you can add members to it

---

## Part 3 — Add a Child to an Existing Household

Children are added through their household so they are linked to their family.

### Steps

1. Go to **Households** (`/#/households`)
2. Search for and click the family's household
3. Inside the household record, click **Edit Household**
4. Click **Add Member**
5. Fill in the child's details:
   - First Name, Last Name
   - Date of Birth (important for age-based room assignments at check-in)
   - Role: set to **Member** or leave as Guest if not formally enrolled
   - Any allergies or special notes (stored in the profile)
6. Click **Save**

The child now appears in the household and is searchable in the Kids Check-In kiosk.

---

## Part 4 — Link a Member to a Household

If a member was added before a household was created:

1. Open the member's record from **Members** (`/#/members`)
2. Click **Edit**
3. Find the **Household** field and select the correct family
4. Save — the member is now linked
