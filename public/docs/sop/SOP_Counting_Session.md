# Standard Operating Procedure: Counting Session Workflow
**Promised Land Christian Center (PLCC)**  
**Department:** Finance / Treasury  
**Effective Date:** April 21, 2026  
**Status:** Active

---

## 1. Overview
The **Counting Session Workflow** is PLCC's official procedure for accurately counting, recording, and reconciling all cash, check, and digital donations received during services and events. This process ensures financial integrity, accountability, and proper stewardship of church resources.

> [!IMPORTANT]
> Accurate counting and reconciliation protects the church from financial discrepancies and maintains donor trust through transparent financial management.

---

## 2. Primary Purposes

### A. Financial Accuracy
Ensure every dollar is properly counted and recorded:
- **Cash Counting**: Accurate denomination-based counting
- **Check Recording**: Individual check details and amounts
- **Digital Tracking**: Online and text giving reconciliation
- **Total Reconciliation**: Match physical to recorded amounts

### B. Accountability & Transparency
Maintain multiple layers of verification:
- **Two-Person Rule**: Never count alone
- **Witness Signatures**: Both counters sign off
- **Audit Trail**: Complete record of all transactions
- **Variance Documentation**: Explain any discrepancies

### C. Secure Processing
Protect church assets throughout the process:
- **Locked Environment**: Count in secure location
- **Immediate Recording**: Enter data in real-time
- **Bank Deposit Preparation**: Secure transport to bank
- **Receipt Generation**: Provide deposit confirmation

---

## 3. Counting Session Process (Step-by-Step)

### Step 1: Pre-Count Preparation
**Staff Action:**
1. Gather required materials:
   - Offering bags/boxes from service
   - Calculator
   - Deposit slips
   - Counting sheets
   - Laptop with PLCC Connect access
2. Verify two authorized counters are present:
   - Finance team member
   - Secretary or Assistant Secretary
3. Secure counting room:
   - Lock door
   - Close blinds
   - Silence phones

**What Happens:**
- Counting environment is secured
- All materials are ready
- Two-person accountability is established

---

### Step 2: Open Counting Session in System
**Staff Action:**
1. Navigate to **Finance → Counting Session**
2. Click "Start New Session"
3. Enter session details:
   - Service date and time
   - Service type (Sunday Morning, Wednesday, Special Event)
   - Counter names (both people present)
   - Location
4. Click "Begin Counting"

**What Happens:**
- New counting session is created in database
- Session ID is generated
- Timestamp is recorded
- Audit log entry is created

---

### Step 3: Count Cash by Denomination
**Staff Action:**
1. Empty all cash from offering containers
2. Sort bills by denomination:
   - $100 bills
   - $50 bills
   - $20 bills
   - $10 bills
   - $5 bills
   - $1 bills
3. Count each denomination twice
4. Enter quantities in system:
   - System calculates totals automatically
5. Count coins:
   - Quarters, Dimes, Nickels, Pennies
6. Enter coin totals

**What Happens:**
- System calculates total cash amount
- Running total is displayed
- Each denomination is recorded separately

---

### Step 4: Record Checks Individually
**Staff Action:**
1. Separate all checks from cash
2. For each check, enter:
   - Check number
   - Donor name (from check)
   - Amount
   - Bank name (optional)
   - Memo/Fund designation (if noted)
3. Verify check is signed and dated
4. Stamp check "For Deposit Only - PLCC"
5. Stack checks in order

**What Happens:**
- Each check is recorded as individual transaction
- System matches donor name to member records
- Check total is calculated automatically
- Donor giving history is updated

---

### Step 5: Reconcile Digital Giving
**Staff Action:**
1. Log in to payment processor (Stripe, PayPal, etc.)
2. Pull transaction report for service date
3. Enter digital transactions:
   - Online giving
   - Text-to-give
   - Mobile app donations
4. Match amounts to processor report
5. Note any processing fees

**What Happens:**
- Digital giving is added to session total
- Transactions are linked to donor records
- Net amount (after fees) is calculated
- Complete giving picture is established

---

### Step 6: Calculate Session Totals
**Staff Action:**
1. Review session summary:
   - Total Cash: $______
   - Total Checks: $______
   - Total Digital: $______
   - **Grand Total: $______**
2. Verify all amounts are correct
3. Check for any discrepancies
4. If variance exists:
   - Recount cash
   - Verify check amounts
   - Document reason for variance

**What Happens:**
- System calculates grand total
- Variance is highlighted if present
- Session summary is prepared

---

### Step 7: Fund Allocation
**Staff Action:**
1. Review designated giving:
   - General Fund
   - Building Fund
   - Missions
   - Youth Ministry
   - Special Offerings
2. Allocate amounts to appropriate funds:
   - Use check memos for designation
   - Use envelope markings
   - Default undesignated to General Fund
3. Verify fund totals match grand total

**What Happens:**
- Giving is distributed to correct funds
- Fund balances are updated
- Designated giving is honored

---

### Step 8: Finalize and Sign Off
**Staff Action:**
1. Both counters review complete session
2. Verify all information is accurate
3. Both counters digitally sign in system:
   - Counter 1 signature
   - Counter 2 signature
4. Add any notes or comments
5. Click "Finalize Session"
6. Print session report (2 copies)

**What Happens:**
- Session is locked (cannot be edited)
- Audit log is updated
- Signatures are timestamped
- Report is generated for records

---

### Step 9: Prepare Bank Deposit
**Staff Action:**
1. Complete bank deposit slip:
   - Total cash amount
   - Total check amount
   - List individual checks (if required)
2. Place cash and checks in deposit bag
3. Seal bag and record seal number
4. Store in church safe until bank run
5. Schedule deposit within 24 hours

**What Happens:**
- Physical deposit is prepared
- Deposit amount matches session total
- Funds are secured
- Bank deposit record is created in system

---

### Step 10: Post-Session Documentation
**Staff Action:**
1. File printed session report
2. Update bank deposit tracking
3. Generate donor receipts (if needed)
4. Update finance dashboard
5. Notify pastor of session completion

**What Happens:**
- Complete paper trail is established
- Finance records are updated
- Leadership is informed
- Process is complete

## 4. Special Scenarios

### A. Variance/Discrepancy Found
**Process:**
1. STOP and recount everything
2. Verify calculator accuracy
3. Check for missed items
4. If variance persists:
   - Document exact amount of variance
   - Note whether over or under
   - Add detailed explanation
   - Notify Finance Administrator
5. Proceed with finalization
6. Investigate cause after session

### B. Large Cash Donations ($500+)
**Process:**
1. Count large bills separately
2. Verify amount multiple times
3. Note in session comments
4. Consider requesting donor information
5. Deposit same day if possible
6. Notify pastor of large gift

### C. Foreign Currency or Non-Cash Items
**Process:**
1. Do NOT include in cash count
2. Set aside for separate handling
3. Note in session comments
4. Contact Finance Administrator
5. Determine appropriate conversion/handling
6. Document separately

### D. Damaged or Questionable Checks
**Process:**
1. Set aside from regular checks
2. Verify check is properly signed
3. Check for sufficient information
4. If questionable:
   - Contact donor for clarification
   - Do NOT deposit until verified
   - Note in session comments
5. Process separately once verified

## 6. Security & Compliance Standards

> [!WARNING]
> **NEVER count alone. ALWAYS have two authorized people present.**

### Critical Rules:
1. **Two-Person Rule**: Mandatory for all counting sessions
2. **Secure Location**: Always count in locked room
3. **Immediate Recording**: Enter data during counting, not later
4. **No Interruptions**: Complete session without breaks
5. **Same-Day Deposit**: Deposit within 24 hours maximum
6. **Audit Trail**: Every session must be signed by both counters
7. **Variance Threshold**: Any variance over $10 requires investigation
8. **Cash Handling**: Never remove cash from counting room until deposited

## 7. Troubleshooting

### Issue: System Won't Finalize Session
**Solution:**
- Verify all required fields are completed
- Check that both signatures are present
- Ensure fund allocations match grand total
- Refresh page and try again
- Contact IT if problem persists

### Issue: Cannot Match Check to Donor
**Solution:**
- Search by partial name
- Check for alternate spellings
- Look up by phone or email
- Create "Unknown Donor" entry temporarily
- Follow up to identify donor later

### Issue: Digital Giving Doesn't Match Processor
**Solution:**
- Verify date range in processor report
- Check for pending transactions
- Account for processing fees
- Look for refunds or chargebacks
- Contact payment processor support
