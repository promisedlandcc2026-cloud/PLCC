# Standard Operating Procedure: Member Onboarding
**Promised Land Christian Center (PLCC)**  
**Department:** Administration / Membership  
**Effective Date:** April 21, 2026  
**Status:** Active

---

## 1. Overview
The **Member Onboarding Process** is PLCC's official procedure for welcoming new members into the church family. This process ensures every new member is properly registered, assigned appropriate access, and integrated into the church community with excellence and care.

> [!IMPORTANT]
> Proper onboarding creates a strong foundation for member engagement and ensures accurate records for ministry planning and pastoral care.

---

## 2. Primary Purposes

### A. Accurate Record Keeping
Maintain complete and accurate member information:
- **Personal Details**: Name, contact information, demographics
- **Household Assignment**: Family grouping and relationships
- **Role Assignment**: Appropriate access level and permissions
- **Ministry Interests**: Team preferences and spiritual gifts

### B. System Access & Security
Ensure proper authentication and authorization:
- **User Account Creation**: Secure login credentials
- **Role-Based Permissions**: Appropriate access to features
- **Access Code Assignment**: 4-digit code for quick check-in
- **Profile Activation**: Enable member portal access

### C. Ministry Integration
Connect new members with ministry opportunities:
- **Team Placement**: Assignment to ministry teams
- **Follow-Up Tracking**: Ensure proper pastoral care
- **Communication Enrollment**: Add to announcement channels
- **Community Access**: Enable chat, prayer wall, and events

---

## 3. Onboarding Process (Step-by-Step)

### Step 1: Initial Contact & Information Gathering
**Staff Action:**
- Receive new member information from:
  - Connect Card submission
  - Plan a Visit registration
  - In-person membership class
  - Direct inquiry
- Verify all required information is complete:
  - First and Last Name (required)
  - Email Address (required)
  - Phone Number (required)
  - Date of Birth
  - Address
  - Emergency Contact

**What Happens:**
- Information is collected in a standardized format
- Incomplete submissions are flagged for follow-up

---

### Step 2: Create Member Profile
**Staff Action:**
1. Navigate to **People → Members → New Member**
2. Enter personal information:
   - Full name
   - Email and phone
   - Date of birth
   - Address
3. Upload profile photo (if available)
4. Add any special notes or pastoral care needs

**What Happens:**
- System creates member record in database
- Unique member ID is generated
- Profile is saved in "Pending" status

---

### Step 3: Household Assignment
**Staff Action:**
1. Determine if member belongs to existing household:
   - **Existing Household**: Search and link to family
   - **New Household**: Create new household record
2. Assign household role:
   - Primary Contact (head of household)
   - Spouse
   - Child
   - Other Family Member
3. Link all family members together

**What Happens:**
- Member is connected to household
- Family relationships are established
- Household name is assigned (e.g., "Smith Family")

---

### Step 4: Role & Permission Assignment
**Staff Action:**
1. Assign appropriate role based on membership status:
   - **MEMBER**: Standard member access
   - **VOLUNTEER**: If serving in ministry
   - **PARENT**: If has children in programs
   - **YOUTH**: If youth group member
   - **MINISTRY_LEADER**: If leading a team
2. Review permission implications:
   - Dashboard access
   - Giving portal
   - Event registration
   - Community features
3. Generate 4-digit access code for check-in

**What Happens:**
- Role determines feature access
- Permissions are automatically applied
- Access code is created for quick lookup

---

### Step 5: User Account Creation
**Staff Action:**
1. Create login credentials:
   - Email becomes username
   - Temporary password is generated
2. Send welcome email with:
   - Login instructions
   - Temporary password
   - Password reset link
   - Getting started guide
3. Enable account activation

**What Happens:**
- User receives welcome email
- Account is created in authentication system
- Member can log in to PLCC Connect

---

### Step 6: Ministry Integration
**Staff Action:**
1. Review member's ministry interests
2. Assign to appropriate teams:
   - Navigate to **People → Teams**
   - Add member to relevant teams
3. Create follow-up task:
   - Assign to ministry leader
   - Set due date (7 days)
   - Add welcome call note
4. Enroll in communication channels:
   - General announcements
   - Relevant ministry updates

**What Happens:**
- Member appears on team rosters
- Ministry leader is notified
- Follow-up task is created
- Member receives church communications

---

### Step 7: Verification & Activation
**Staff Action:**
1. Review all information for accuracy
2. Verify household connections
3. Confirm role and permissions
4. Change status from "Pending" to "Active"
5. Document completion in audit log

**What Happens:**
- Member profile is fully activated
- All features become accessible
- Member appears in active directory
- Onboarding is complete

---

## 4. Special Scenarios

### A. Family Onboarding (Multiple Members)
**Process:**
1. Create household first
2. Add primary contact (head of household)
3. Add spouse with "Spouse" role
4. Add children with "Child" role and ages
5. Assign one user account per adult
6. Link all members to same household

### B. Visitor to Member Conversion
**Process:**
1. Locate existing visitor record from Connect Card
2. Update status from "Guest" to "Member"
3. Complete missing information
4. Create user account
5. Assign to household
6. Update follow-up task to "Completed"

### C. Transfer Members (From Another Church)
**Process:**
1. Request transfer letter (if applicable)
2. Create member profile with transfer date
3. Add note about previous church
4. Assign "Member" role immediately
5. Schedule pastoral welcome meeting
6. Integrate into ministry teams

### D. Youth Members (Under 18)
**Process:**
1. Create member profile with parent information
2. Assign "Youth" role
3. Link to parent's household
4. Do NOT create separate user account
5. Parent manages youth profile
6. Assign to youth ministry team

## 6. Quality Standards

> [!WARNING]
> **Incomplete onboarding creates confusion and poor member experience.**

### Critical Requirements:
1. **Complete Information**: Never activate a profile with missing required fields
2. **Accurate Roles**: Wrong role assignment creates security and access issues
3. **Household Accuracy**: Incorrect family links cause check-in and communication problems
4. **Timely Processing**: New members should be fully onboarded within 48 hours
5. **Follow-Up Assignment**: Every new member must have a follow-up task created

---

## 7. Troubleshooting

### Issue: Member Cannot Log In
**Solution:**
- Verify email address is correct in profile
- Check that user account was created
- Send password reset link
- Verify account status is "Active" not "Pending"

### Issue: Wrong Household Assignment
**Solution:**
- Navigate to member profile
- Edit household field
- Select correct household or create new one
- Save changes and verify family links

### Issue: Incorrect Permissions
**Solution:**
- Review member's role assignment
- Change role if incorrect
- Permissions update automatically
- Have member log out and back in

### Issue: Duplicate Member Records
**Solution:**
- Identify the correct/complete record
- Merge information if needed
- Delete duplicate record
- Update household links
- Document in audit log

---

## 8. Data Privacy & Security

### CRITICAL RULES:
1. **Confidentiality**: Member information is strictly confidential
2. **Access Control**: Only authorized staff can create/edit member records
3. **Password Security**: Never share temporary passwords verbally in public
4. **Audit Trail**: All changes are logged automatically
5. **Data Accuracy**: Verify information before activation
