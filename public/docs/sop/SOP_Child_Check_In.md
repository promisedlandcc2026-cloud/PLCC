# Standard Operating Procedure: Child Check-In System
**Promised Land Christian Center (PLCC)**  
**Department:** Children's Ministry / Events  
**Effective Date:** April 21, 2026  
**Status:** Active

---

## 1. Overview
The **Child Check-In System** is PLCC's secure and efficient process for registering children's attendance at services and events. This system ensures child safety, provides accurate attendance records, and creates a smooth experience for families while maintaining the highest standards of security.

> [!IMPORTANT]
> This system protects our most precious members while allowing parents to worship with peace of mind, knowing their children are safe and accounted for.

---

## 2. Primary Purposes

### A. Child Safety & Security
Ensure every child is properly tracked and can only be released to authorized guardians:
- **Security Codes**: Unique codes generated at check-in for pickup verification.
- **Room Assignments**: Age-appropriate placement (Nursery, Pre-K, Elementary, Middle School).
- **Printed Labels**: Physical tags with child name, room, and security code.
- **Authorized Pickup**: Only adults with matching security codes can retrieve children.

### B. Attendance Tracking
Maintain accurate records of children's ministry participation:
- **Database Records**: Timestamped check-ins stored in the attendance system.
- **Historical Data**: Track patterns and engagement over time.
- **Ministry Planning**: Use attendance trends to plan staffing and resources.

### C. Family Experience
Create a welcoming and efficient check-in process:
- **Quick Search**: Find families by name or 4-digit access code.
- **Multiple Check-In Options**: Kiosk mode for staff or mobile express for families.
- **Visitor Registration**: On-the-fly registration for first-time guests.

---

## 3. Check-In Process (Step-by-Step)

### Step 1: Search for Family
**Staff Action:**
- Open the Kids Check-In page in PLCC Connect.
- Search using one of three methods:
  - **Family Name**: Type the household name (e.g., "Smith Family").
  - **Parent/Child Name**: Type any family member's first or last name.
  - **Access Code**: Enter the family's 4-digit code for instant lookup.

**What Happens:**
- System searches the database and displays matching families.
- All household members and their children appear in the results.

---

### Step 2: Select Children to Check In
**Staff Action:**
- Review the family members displayed.
- Select the specific children attending today by clicking their names.
- Verify any special notes or allergies displayed on their profile.

**What Happens:**
- Selected children are highlighted and prepared for check-in.
- System automatically assigns age-appropriate rooms:
  - **Under 3 years**: Nursery
  - **3-5 years**: Pre-K
  - **6-10 years**: Elementary
  - **11+ years**: Middle School

---

### Step 3: Complete Check-In
**Staff Action:**
- Click the "Check In" button to finalize.
- Wait for the security code to generate.
- Print the security labels (one for parent, one for each child).

**What Happens:**
- System creates attendance records in the database.
- Unique security code is generated (e.g., "7342").
- Labels print automatically with:
  - Child's name
  - Room assignment
  - Security code
  - Date and time
- Parent receives their security tag.

---

### Step 4: Direct Child to Room
**Staff Action:**
- Hand the child's label to the parent or attach to the child.
- Direct the family to the appropriate room(s).
- Remind parent to keep their security tag for pickup.

**What Happens:**
- Child proceeds to their assigned room.
- Room volunteers verify the child's label matches their roster.

---

### Step 5: Pickup Process
**Staff/Volunteer Action:**
- When parent arrives for pickup, verify their security code matches the child's tag.
- **CRITICAL**: Only release the child if codes match exactly.
- Remove and dispose of security labels after successful pickup.

**What Happens:**
- Child is safely released to authorized guardian.
- Check-in process is complete.

---

## 4. Special Scenarios

### A. First-Time Visitors
**Process:**
1. Click "Register Visitor" button.
2. Collect basic information:
   - Parent first and last name
   - Email and phone number
   - Child(ren) names and ages
3. System creates temporary household record.
4. Proceed with normal check-in process.
5. Assign temporary access code for future visits.

### B. Multiple Children from Same Family
**Process:**
- Select all children checking in during Step 2.
- System generates ONE security code for the entire family.
- Print labels for each child with the same code.
- Parent receives one security tag valid for all children.

### C. Late Arrivals
**Process:**
- Follow normal check-in process even after service starts.
- Escort child to room personally if service is in progress.
- Notify room volunteer of late arrival.

### D. Early Pickup
**Process:**
- Verify security code as normal.
- Note early pickup time in system if tracking is needed.
- Ensure child's belongings are collected.

| **System Administrator** | Maintain database, troubleshoot issues | As needed |

## 6. Security Guidelines

> [!WARNING]
> **NEVER release a child without verifying the security code matches exactly.**

### Critical Rules:
1. **No Exceptions**: Even if you recognize the parent, verify the code.
2. **Lost Tags**: If parent loses their security tag, verify identity with photo ID and look up the code in the system.
3. **Suspicious Behavior**: If anyone attempts to pick up a child without proper authorization, notify leadership immediately.
4. **Code Privacy**: Do not share security codes verbally in public areas.

---

## 7. Troubleshooting

### Issue: Family Not Found in Search
**Solution:**
- Try alternate spellings or partial names.
- Search by individual member names instead of household.
- Check if they're registered as a visitor.
- Register as new visitor if truly first-time.

### Issue: Printer Not Working
**Solution:**
- Check printer connection and paper.
- Manually write security code on blank labels as backup.
- Report issue to tech team immediately.

### Issue: Wrong Room Assignment
**Solution:**
- Manually override room assignment before printing.
- Update child's age in the system for future accuracy.
